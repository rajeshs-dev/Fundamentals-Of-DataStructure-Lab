## 💻 How to Run the Programs

**Step 1:** Clone the repository.

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 2:** Open the project folder.

**Step 3:** Compile the C program.

```bash
gcc program.c -o program
```

**Step 4:** Execute the program.

```bash
./program
```
